# Project Summary (Based on Reviewed Files)

## README.md
- **Purpose**: Project overview, features, installation instructions, configuration details (database, security, GUI, logging), usage guide, project structure, dependencies, and error handling information. Mentions UI and file-based config for logging/Syslog.

## main.py
- **Purpose**: Main entry point. Sets up logging (including Syslog via `app_settings.json` and JSON formatter), handles signals, launches GUI.

## gui/main_window.py
- **Purpose**: Defines the `BGPMonitorGUI` class, the main graphical user interface.
- **Responsibilities**:
    - Builds the UI layout (control panel, log display, security alerts panel).
    - Handles user interactions (region/collector selection, AS filtering, button clicks).
    - Provides UI dialogs for DB and Syslog configuration (`app_settings.json`).
    - Manages application state (monitoring status, selected filters).
    - **Maintains in-memory cache (`prefix_origin_cache`) for tracking last seen origin AS per prefix.**
    - Loads/saves GUI settings (`gui_settings.json`) and App settings (`app_settings.json`).
    - Initiates and controls the BGP monitoring process (`src/bgp_monitor.py`) in a separate thread.
    - Displays BGP updates and security alerts.
    - Calls `utils/security_analyzer.py` (`check_suspicious_patterns`) with current and previous origin AS for alert generation.

## src/bgp_monitor.py
- **Purpose**: Defines the `BGPMonitor` class for handling the live BGP data stream.
- **Responsibilities**:
    - Connects to the RIPE RIS WebSocket endpoint.
    - Subscribes to specified BGP collectors.
    - Receives BGP messages (JSON format).
    - Manages the WebSocket connection (keepalives, error handling).
    - Passes received messages to a callback function (`BGPMonitorGUI.process_update`) for processing.
    - Optionally initializes `utils/db_manager.py`.

## utils/security_analyzer.py
- **Purpose**: Performs security analysis on BGP updates using configurable heuristics.
- **Responsibilities**:
    - Loads security lists (critical prefixes, bad actors) from `config/security_config.json`.
    - **Loads heuristic settings (thresholds, severities, enable flags for long_path, prepending, more_specific) from `app_settings.json`.**
    - **Checks for BGP hijacks using previous origin AS data (passed from GUI cache).**
    - Detects potential route leaks (valley-free path validation using AS relationship data).
    - Analyzes AS paths (prepending, unusual transit) based on configured thresholds.
    - Identifies impacts on critical prefixes.
    - Validates RPKI status using RIPEstat API (`RPKIValidator` class), clarifying "None" reasons.
    - Logs detected security alerts (`SecurityAlertLogger` class) using standard Python logging (with structured `extra` data) and optionally to CSV/DB.
    - Uses `utils/bgp_utils.py` for AS relationships and `utils/as_lookup.py` for AS details.

## utils/db_manager.py
- **Purpose**: Defines the `BGPDatabaseManager` class to manage Neo4j database operations.
- **Responsibilities**:
    - Establishes and manages the Neo4j database connection.
    - Initializes the graph schema.
    - Stores BGP updates and security alerts.
    - Provides methods to query the database.
    - Exports alerts from the database to CSV.

## utils/config_manager.py
- **Purpose**: Manages loading/saving configuration.
- **Responsibilities**:
    - Handles Neo4j config (`db_config.json`, `database_config.ini`).
    - Handles GUI state (`gui_settings.json`).
    - **Handles application settings (`app_settings.json`), including logging/Syslog and security heuristic configurations.** Uses deep merge for loading.

## utils/bgp_utils.py
- **Purpose**: Utility functions for BGP data processing, including AS relationship loading.
- **Responsibilities**:
    - Validates ASNs, prefixes. Formats timestamps, communities.
    - **Loads AS relationship data from CAIDA file (`data/as_relationships.txt.bz2`) for route leak analysis.** Includes comments explaining the source requirement.
    - Provides `get_as_relationship` function.

## IMPROVEMENT_PLAN.md
- **Purpose**: Documents the analysis of security features and the plan for improvements (state management, heuristics, formatting, config).
