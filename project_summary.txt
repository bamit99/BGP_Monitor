## Directories

*   `.git/`: Contains Git repository metadata.
*   `cache/`:
    *   `as_cache.json`: Stores cached results from AS number lookups (`utils/as_lookup.py`).
*   `config/`: Contains configuration files.
    *   `collectors.py`: Defines BGP collector information (regions, locations).
    *   `database_config.py`: Handles Neo4j connection details and status checks.
    *   `database_config.ini`, `database_config_template.ini`: INI format for Neo4j configuration.
    *   `db_config.json`, `db_config.json.template`: JSON format for Neo4j configuration.
    *   `gui_settings.json`: Stores user preferences for the GUI (region, selected collectors, AS filters).
    *   `security_config.json`: Stores lists of critical prefixes, UK telecom ASNs, trusted transit ASNs, and known bad actors used by the security analyzer.
    *   `user_settings.json`: (Purpose unclear from review, potentially unused or for future features).
*   `data/`: Default directory for storing runtime data.
    *   `as_relationships.txt.bz2` (Expected by `bgp_utils.py`): CAIDA AS relationship data file (used for route leak detection).
    *   `security_alerts/`: Stores daily CSV logs of detected security alerts (`utils/security_analyzer.py`).
    *   `bgp_updates_YYYYMMDD_HHMM.csv`: Stores raw BGP updates logged via CSV (`utils/data_manager.py`).
*   `gui/`: Contains the Graphical User Interface code.
    *   `main_window.py`: Defines the main `BGPMonitorGUI` class, orchestrating the UI, monitoring, data processing, and analysis components.
    *   `config_dialog.py`: (Not reviewed, likely the dialog window for DB configuration).
*   `sample_data/`: (Not reviewed, likely contains sample BGP data or reports).
*   `src/`: Contains the core application logic.
    *   `bgp_monitor.py`: Handles the WebSocket connection to RIPE RIS, subscribes to collectors, receives BGP messages, and manages keepalives.
    *   `connection_manager.py`: (Not reviewed, potentially refactored connection logic).
*   `tests/`: Contains test scripts.
    *   `query_suspicious.py`, `test_neo4j_connection.py`, `test_security_analyzer.py`, `test_websocket.py`, `validate_neo4j_data.py`, `verify_live_updates.py`: Various test scripts.
    *   `test_ui/`: Contains UI test related files.
*   `utils/`: Contains utility modules.
    *   `analysis.py`: (Imported by `gui/main_window.py` as `BGPAnalyzer`, but file not present in listing - potentially removed or renamed).
    *   `as_lookup.py`: Looks up ASN details from public sources (PeeringDB, RADB, RIRs) with caching.
    *   `bgp_utils.py`: Provides helper functions for validating/formatting BGP data and loading/querying AS relationship data.
    *   `config_manager.py`: Manages loading and saving application configurations (DB, GUI settings) from different file formats/locations.
    *   `data_manager.py`: Handles saving raw BGP updates to daily CSV files.
    *   `db_manager.py`: Manages all interactions with the Neo4j database (storing updates/alerts, querying data, schema initialization).
    *   `security_analyzer.py`: Contains the core logic for analyzing BGP updates for security threats (hijacking, leaks, RPKI invalidity, etc.) based on configured rules. Includes the `SecurityAlertLogger`.
    *   `ui_config_handler.py`: (Not reviewed, potentially related to GUI configuration persistence).

## Overall Functionality

The BGP Monitor connects to RIPE RIS, collects live BGP updates, allows filtering by AS, processes updates, performs security analysis (detecting hijacks, leaks, RPKI issues, path problems), stores data in Neo4j and/or CSV files, and presents information and alerts through a Tkinter GUI.
